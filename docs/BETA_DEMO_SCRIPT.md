# Beta Demo Script

Use this script for the first Overview360 beta walkthrough. Keep the demo framed as operational audit readiness, not certification or advice.

## Setup

1. Confirm the app is running in demo mode for sample-data walkthroughs:
   `NEXT_PUBLIC_VIGILEN_APP_MODE=demo`
2. Open `/login`.
3. Sign in with any demo email and password.
4. If the demo data is messy, open `/dashboard` and use `Reset Demo Data`.

## Walkthrough

1. Dashboard
   - Show the first-run checklist.
   - Explain readiness scoring: Green=100, Amber=50, Red=0, Grey excluded.
   - Show Top 10 Risks, Missing Evidence, Overdue Reviews and Open Actions.

2. Requirements
   - Open `/dashboard/requirements`.
   - Click `Import Template Pack`.
   - Preview a pack, deselect one item, and import the rest.
   - Open a requirement detail panel.
   - Show linked documents, actions, reviews and status.

3. Evidence Vault
   - Open `/dashboard/vault`.
   - Upload a supported file type.
   - Select the uploaded record.
   - Edit metadata and link it to a requirement.
   - Open the private file link to show signed URL behaviour.

4. Readiness Update
   - Return to `/dashboard`.
   - Show how the score and reason panels reflect requirement and evidence changes.

5. Audit Pack Builder
   - Open `/dashboard/audit-packs`.
   - Name a pack.
   - Select requirements.
   - Review linked evidence, warnings and actions.
   - Save as Draft.
   - Export CSV or use Print/PDF summary.

## Boundaries to Say Out Loud

- Overview360 organises evidence and highlights operational gaps.
- Overview360 does not provide legal advice.
- Overview360 does not provide safety advice.
- Overview360 does not certify compliance or guarantee audit outcomes.
- Private evidence files are not public links.

## Close

Ask beta users:

- Which workflow felt unclear?
- Which evidence records are hardest to organise today?
- Which dashboard warnings are most useful?
- What would make the audit pack easier to review?
